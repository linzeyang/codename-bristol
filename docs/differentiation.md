# 差异化设计：声屿 vs. X

> 依据均来自 `materials/screenshots/`。所有改进项都在本原型中实现，可按「如何验证」逐项操作。
> 视觉与交互为原创：不复用 X 的 Logo、品牌色、图标、图片或文案；仅参考其信息架构类别。

## 0. 设计定位

| 维度 | X（截图证据） | 声屿（本原型） |
| --- | --- | --- |
| 主题 | 深黑底 + 荧光绿强调（`01/02/09/11.jpeg`） | **亮色纸张为主**的编辑式界面（米白 `#F6F1E7` / 墨黑 / 朱砂 `#E84A2A` / 深青 `#0D6E66`），并原创「夜航」暗色主题 |
| 字体 | 无衬线、紧凑小字（`01/02.jpeg`） | 大字号衬线标题 + 无衬线正文 + 等宽元数据，中英文混排编辑风格 |
| 图像 | 艺人圆头像、实拍封面（`01/02/14.jpeg`） | **程序化生成的原创 SVG 封面/头像**（波纹、拱形、日轮、格点等 7 种图案），不包含任何竞品图片 |
| 布局 | 固定黑底侧栏 + 均质卡片网格（`01/11.jpeg`） | 杂志式不对称首屏、带编号的规则线、错位卡片与「纸张」层叠；艺人使用方圆形海报而非圆形头像 |
| 品牌 | 红色/绿色图形标识（`01/12.jpeg`） | 声屿原创标记：三道渐次靠岸的弧线组成「屿」，字标「声屿 SONORA ISLE」 |
| 调性 | 商业化、促销驱动（底部订阅横幅 `01.jpeg`） | 安静、内容优先；订阅与隐私入口透明且不打断播放 |

## 1. 问题与改进总览

| # | X 的体验缺口（证据） | 声屿改进 | 验证入口 |
| --- | --- | --- | --- |
| 1 | 搜索只是顶部输入框，AI 问答被埋在账户帮助页（`01.jpeg`、`05.jpeg`） | **⌘K 命令面板 + 声屿向导**：全局唤起、直接找歌、离线可用的意图引擎 | 任意页面 ⌘K；侧栏「向导」 |
| 2 | 首页只有通用运营货架，没有任何推荐解释（`01.jpeg`） | **可解释推荐 + 口味调音台**：每张推荐卡显示理由，滑杆即时改变结果 | 首页「为你挑选」/「调音台」 |
| 3 | 歌词全屏、右侧正在播放、底部播放条三套上下文割裂；队列仅能"加入"看不到编辑（`10.jpeg`、`11.jpeg`） | **舱内工作台**：歌词/队列/信息在同一面板，队列可跳播、排序、移除、清空 | 播放条展开「舱内视图」 |
| 4 | 次级文字对比度低、11px 灰字、纯图标按钮缺少可见标签（`01/02/09/10.jpeg`） | **键盘与无障碍成为主路径**：AA 对比度、44px 命中区、完整焦点环、ARIA 标签、跳转链接、动效降级 | 仅用键盘完成一次播放；按 `?` |
| 5 | 仅暗色主题；底部订阅横幅持续遮挡内容、账户页重复推销（`01/05.jpeg`） | **亮/暗双主题**（亮色为默认）+ 无固定推销条 | 顶栏主题切换 |
| 6 | 设置分散在账户页与设置页、隐私/导出/退出不透明（`05/06.jpeg`） | **透明的订阅与数据主权**：当前套餐、模拟切换明确提示不扣款；隐私模式、JSON 导出、全设备退出、删号 | 「订阅」「账户」页 |
| 7 | 全屏歌词与歌曲页都会挤压/移除音乐库，跳转后上下文丢失（`10/11.jpeg`） | **持久外壳 + 不打断导航**：侧栏、顶栏、播放条常驻；舱内视图为侧滑而非换页 | 在任意页面打开舱内视图 |

## 2. 六项核心改进（详细）

### D1. ⌘K 命令面板 + 声屿向导（自然语言找歌）

**改进什么**
- 任意页面按 `⌘K` / `Ctrl+K` 唤起命令面板：可跳转页面、即时搜索歌曲/艺人/专辑/歌单/播客，也可把输入直接交给「声屿向导」。
- 向导支持中文自然语言，如「适合雨夜写代码的歌」「想听点像林晚星但更新鲜的」「给我 20 分钟通勤歌单」。结果附带**匹配理由**与一键播放。
- 无 `LLM_*` 环境变量时使用本地意图引擎（情绪/风格/场景/艺人/时长解析），完全离线可用；配置 OpenAI 兼容端点后自动增强，失败时静默回退本地。

**为什么更好（证据）**
- X 的全站搜索只有顶部一个输入框（`01.jpeg`），而 AI 问答入口位于账户页顶部，语义是"账户帮助"而非音乐发现（`05.jpeg`）——发现音乐的最短路径仍要经过关键词与多层货架。
- 命令面板把「导航 + 搜索 + 提问 + 动作」合并为一个入口，键盘用户无需离开当前页面，减少上下文切换。

**如何验证**
1. 登录后在任意页面按 ⌘K，输入「深夜」——出现跨类型结果。
2. 按 ↓ 选择「向向导提问：深夜」，回车进入向导页，得到带理由的曲目并能一键播放。
3. 断开网络/不配置 LLM 密钥时以上步骤仍完整可用。

**实现位置**
- 前端 `CommandPalette.tsx`、`GuidePage.tsx`；后端 `routes/assistant.ts`、`services/assistant.ts`。

---

### D2. 可解释推荐 + 口味调音台

**改进什么**
- 「为你挑选」每张卡带一枚理由标签：`因为你关注了 林晚星` / `因为你喜欢民谣` / `最近常听 北纬三十` / `编辑精选 · 深夜`。
- 首页调音台提供三根滑杆：**熟悉度 / 能量 / 新鲜度**；拖动后立即请求新推荐（防抖），结果与理由同步更新。
- 推荐算法使用点赞（权重 3）、关注（权重 2）、播放历史（权重 1）构建风格画像，再叠加曲目热度、新旧与调音参数；游客看到编辑精选。

**为什么更好（证据）**
- X 首页是 Trending / Popular / Popular 的同一套通用货架（`01.jpeg`），用户无法知道为何看到某内容，也无法调节口味。
- 可解释性建立信任，调音台把"黑盒推荐"变成可操作的偏好控制，且**不依赖第三方画像**。

**如何验证**
1. 用演示账号在任意歌曲点「喜欢」，回到首页，「为你挑选」出现含风格理由的卡片。
2. 把「能量」滑杆从低拖到高，等待结果刷新，歌曲风格与理由发生变化；刷新页面参数仍保留（本地保存）。

**实现位置**
- 后端 `services/recommend.ts`、`GET /api/home`；前端 `pages/HomePage.tsx`（内嵌调音台）、`components/ArtCard.tsx`（理由标签）。

### D3. 舱内工作台（播放 / 歌词 / 队列 / 信息）

**改进什么**
- 底部播放条常驻；点击封面或「舱内视图」从右侧滑出工作台，包含：大封面与进度、同步高亮歌词、**可编辑队列**（点击跳播、上移/下移、移除、清空、查看来源）、曲目/艺人/专辑信息与推荐理由。
- 队列与歌词共用一套播放状态；在队列中重排不会打断当前播放；当前曲目有明确标识。
- 手机上工作台变为全屏，但保留关闭手势与播放条。

**为什么更好（证据）**
- X 把歌词放在独立全屏页（`10.jpeg`），同时歌曲页又有右侧正在播放面板（`11.jpeg`）、底部播放条，三处重复且互相割裂；队列只出现在"Add to queue"菜单项（`10.jpeg`），没有可见的编辑界面。
- 声屿把高频上下文聚合，用户不必在三种布局间跳转；队列编辑从"只能添加"升级为"可管理"。

**如何验证**
1. 播放任意歌曲，点击播放条封面打开舱内视图。
2. 切到「歌词」，观察当前行随进度高亮；切到「队列」把第 3 首上移，点击它跳播。
3. 全程页面路由不变，侧栏与音乐库状态保留。

**实现位置**
- 前端 `PlayerContext.tsx`、`components/NowPlaying.tsx`（歌词、队列与信息在同一组件内）。

### D4. 键盘优先与无障碍

**改进什么**
- 全局快捷键：`Space` 播放/暂停、`←/→` ±5 秒、`Shift+←/→` 上一首/下一首、`L` 喜欢当前曲目、`Q` 打开队列、`/` 聚焦搜索、`⌘K` 命令面板、`?` 快捷键说明、`Esc` 关闭浮层。
- 语义化结构、跳过导航链接、可见焦点环、所有纯图标按钮有 `aria-label`、动态播放状态通过 `aria-live` 播报、焦点陷阱与 Esc 关闭弹层。
- 字号/对比度满足 WCAG AA；播放与导航等关键操作命中区 ≥ 44×44，列表次级图标按钮为 34×34 且均带 `aria-label`；`prefers-reduced-motion` 与设置中的「减少动效」同时生效。

**为什么更好（证据）**
- X 的元数据大量使用 11–12px 低对比灰字（`01.jpeg` 页脚、`02.jpeg` 播放次数、`09.jpeg` 时长），全屏播放页的控制几乎都是无文字图标（`10.jpeg`），依赖鼠标悬停。
- 键盘与读屏可用性既是体验改进，也是面向企业/教育客户的采购要求。

**如何验证**
1. 不使用鼠标：`Tab` 进入页面 → `/` 搜索 → 进入歌曲 → `Space` 播放 → `L` 喜欢 → `Q` 查看队列 → `?` 查看快捷键。
2. 顶栏「减少动效」或系统设置后，过渡动画显著减少。

**实现位置**
- 前端 `components/AppShell.tsx`（全局快捷键）、`components/ShortcutSheet.tsx`、全局样式焦点环与 reduced-motion 规则。

---

### D5. 亮暗双主题与原创视觉系统

**改进什么**
- 默认「纸张」亮色主题：米白纸面、墨色排版、朱砂强调、深青辅助；「夜航」暗色主题为深海军蓝而非纯黑。
- 专辑/艺人图像由 7 种原创 SVG 图案程序化生成，颜色来自种子数据；不包含竞品截图、Logo 或实拍素材。
- 排版采用衬线大标题 + 等宽编号 + 细规则线，货架使用错位高度与方圆形艺人卡，形成与 X 的深色圆头像网格明显不同的识别度。

**为什么更好（证据）**
- X 全站为深色 + 荧光绿（`01/02/09.jpeg`），视觉上高度同质化；亮色与编辑式排版在白天/办公场景更舒适，且双主题覆盖更多偏好。
- 程序化封面避免版权风险，也让原型可离线自洽运行。

**如何验证**
- 顶栏切换太阳/月亮图标，主题即时切换且刷新后保持；与截图并排查看，配色、字体、卡片形状、头像形状均明显不同。

---

### D6. 透明的订阅与数据主权

**改进什么**
- 套餐页平铺「免费 / 靠岸 Plus / 共听 Studio」，明示当前套餐、模拟计费说明与不扣款提示；切换立即生效，记录订阅事件，无倒计时、无遮挡横幅。
- 账户页把隐私与数据控制放在一级：隐私模式（开启后播放不写历史）、导出 JSON、全设备退出、删除账户（输入邮箱确认）。
- 通知开关只声明站内偏好，明确说明原型不发送邮件，不伪装能力。

**为什么更好（证据）**
- X 在首页底部常驻订阅横幅遮挡内容（`01.jpeg`），账户页又重复 Premium 推销卡（`05.jpeg`），账户与设置功能重叠（`05/06.jpeg`），用户很难判断当前订阅状态与数据控制位置。
- 透明、无干扰、可撤销的设计减少误购与隐私顾虑，也更符合内部评审对"可自建替代"的合规预期。

**如何验证**
1. 「订阅」页切换套餐，顶部当前套餐徽标即时变化，刷新保留，页面明确显示"演示环境不扣款"。
2. 账户页开启隐私模式 → 播放一首歌 →「最近播放」不新增；关闭后再播放则新增。
3. 点击「导出我的数据」下载 JSON，确认不含 `password_hash`；「所有设备退出」后当前会话回到登录页。

**实现位置**
- 后端 `routes/plans.ts`、`routes/settings.ts`；前端 `PlansPage.tsx`、`AccountPage.tsx`。
