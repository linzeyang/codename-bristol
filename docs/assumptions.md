# 实施假设

本文件记录素材不明确、但为完成原型所做的一切判断。验收时若对某功能边界有疑问，以本文件与 `docs/competitor-analysis.md` 第 7 节为准。

## 1. 素材与竞品身份

1. **产品类型**：15 张截图对应一个音乐流媒体服务（音乐、播客、电台、订阅），而非社交或视频优先产品。依据：`01.jpeg` 的歌曲/艺人/专辑/电台货架、`09.jpeg` 曲目表、`07.jpeg` 音乐订阅套餐。
2. **名称与品牌被打码**：截图中 Logo、产品名与下载页命令均被红色涂抹，原型不使用、也不推测其真实名称；一律称为「X」。
3. **语言混杂**：`05.jpeg` 为荷兰语账户页，`12/13.jpeg` 为简体中文登录/注册页。判断该产品支持多语言；原型按任务要求只提供简体中文。
4. **`04.jpeg` 不属于核心体验**：Linux 桌面客户端安装说明页被打码且与 Web 音乐体验无关；仅作为「桌面分发能力」记录，不在原型实现。
5. **截图未展示的二级页面**（搜索空态、队列编辑、下载管理、家长控制等）按行业常识推断，标注为「推断」，不纳入验收。

## 2. 产品与内容假设

6. **原创品牌**：原型命名为「声屿」（英文副标 SONORA ISLE，仅作气质描述，不作为商标使用），主张「在声音里靠岸」。
7. **全部内容为虚构**：艺人、专辑、歌曲、歌词、播客、播放次数、月听众均为原创虚构数据，不对应真实艺人或作品；不复用截图中的任何艺人名、专辑名、图片或文案。
8. **音频素材**：截图不包含可播放音频。原型使用 `scripts/generate-audio.py` 以纯合成方式生成 8 段 45 秒原创氛围样带（MP3），映射到曲目与播客单集。不使用任何第三方录音，因此离线可运行且无版权风险。
9. **封面与头像**：为规避版权并保证离线，全部由前端基于种子数据生成 SVG 图案，不包含位图素材。
10. **时长**：为了与原创样带一致，曲目与单集时长统一为 45 秒；界面明确标注为「原创样带」，不伪装成完整歌曲。
11. **播放次数/月听众**：用于排序展示的虚构统计，不代表真实数据。
12. **歌词**：按情绪从原创诗句模板生成，并分配时间戳用于演示同步高亮；不是真实歌词。

## 3. 用户与权限

13. **登录是产品前提但允许游客浏览**：截图同时存在未登录首页（`01.jpeg`）与登录页（`12.jpeg`）。原型允许游客浏览、搜索、播放；收藏、歌单、音乐库、账户、订阅需要登录。这与截图行为一致。
14. **角色模型**：截图未展示管理后台，但任务要求「如截图显示需要登录/多角色，实现相应用户体系」。原型实现 `listener` 与 `admin` 两种角色，用于演示服务端权限校验；管理员拥有曲目管理能力，不代表竞品真实角色设计。
15. **演示账号**：种子数据包含 `demo@shengyu.app / demo1234`（听众）与 `admin@shengyu.app / admin1234`（管理员）。这是本地演示凭据，已在 README 公开，不属于敏感信息；生产部署时必须删除或修改。
16. **注册字段**：仅邮箱、昵称、密码；不做邮箱验证（无外网邮件服务）。密码要求 ≥ 8 位。
17. **账户恢复**：未实现找回密码/邮箱验证，属于原型范围外；用户可通过管理端重新种子或修改密码流程。
18. **家长控制、恢复歌单、应用管理**：截图有入口但无行为证据，未实现；不列入验收功能清单。

## 4. 订阅与支付

19. **价格与方案为虚构**：免费、靠岸 Plus（¥15/月）、共听 Studio（¥25/月），仅用于展示套餐切换；不接入任何真实支付。
20. **模拟扣款**：切换套餐会立即写入用户资料和订阅事件，不产生真实交易；页面明确提示「演示环境，不扣款」。
21. **不实现成员邀请/家庭共享**：截图中的 Duo/Family 需要账户体系扩展，原型仅在套餐说明中标注该能力为演示文案，不作为可验证功能。
22. **不实现离线下载与无损音质**：无授权音频源；原型中的音质设置只作为偏好展示并在播放器上显示标签，不改变实际码率，文档中明示。

## 5. 功能边界

23. **无广告**：截图有广告偏好设置与 Free 广告；原型不投放广告，因此不实现广告偏好作为可操作项，仅保留在竞品分析中。
24. **音乐视频/Canvas/巡演/周边/桌面端**：素材或基础设施不足，明确排除，不作为验收项。
25. **分享链接**：截图有 Share 菜单，但分享需要公网 URL 与社交配置；原型未实现，不列入验收。
26. **通知**：设置中的通知开关仅持久化偏好，不发邮件/推送；界面明示。
27. **AI 能力**：截图（`05.jpeg`）有 AI 提问框，但未展示回答形式。原型将其扩展为「声屿向导」，离线意图引擎为默认实现；若提供 `LLM_BASE_URL`/`LLM_API_KEY`/`LLM_MODEL`，调用 OpenAI 兼容 `chat/completions` 增强回答，超时或失败自动回退，不阻塞核心功能。
28. **搜索排序**：使用标题/艺人/专辑/描述的子串匹配 + 播放热度排序，不引入外部搜索引擎。
29. **推荐质量**：基于规则和风格画像，不训练模型；目的是展示可解释的推荐交互，不承诺工业级推荐效果。
30. **分页**：原型数据量小，接口返回完整列表；仅搜索历史限制 8 条，队列不设上限。未实现无限滚动分页。

## 6. 工程取舍

31. **数据库**：PostgreSQL 16（关系型），`apps/api/db/schema.sql` 为初始化 schema；启动时幂等执行。测试使用 PGlite（WASM PostgreSQL），不需要外部数据库，保证全新 clone 后可直接跑测试。
32. **代码分层**：采用 Fastify + 原生参数化 SQL（不使用 ORM），以减少依赖与构建复杂度；所有用户输入经 Zod 校验，SQL 全部参数化。
33. **会话**：HttpOnly + SameSite=Lax Cookie 中的 JWT，7 天有效；登出全部设备通过 `token_version` 失效。无刷新令牌，原型可接受。
34. **种子策略**：API 启动时若目录为空则自动种子（`SEED_ON_EMPTY`，默认开启），保证 `docker compose up` 一键可用；`--profile seed` 提供显式幂等重新种子。用户数据不会因重新种子被清空。
35. **数据库安全**：本地 Compose 的 PostgreSQL 仅绑定 `127.0.0.1` 且不对外发布端口，使用 trust 认证；生产需通过 `DATABASE_URL`/`POSTGRES_PASSWORD` 注入。JWT 密钥未设置时启动生成临时随机值（重启后会话失效）并输出警告；生产必须设置 `JWT_SECRET`。
36. **音频存储**：样带随仓库提交（原创），由 API 静态目录提供；不依赖 CDN/对象存储。
37. **浏览器支持**：面向现代常青浏览器（Chrome/Edge/Firefox/Safari 最近两个大版本）；使用原生 `<audio>`、CSS 变量、`color-scheme`。
38. **测试范围**：后端覆盖认证、权限、歌单、推荐理由、搜索、助手、设置、订阅、管理端；前端覆盖播放器队列/随机/循环逻辑、格式化、关键组件与 API 客户端。不包含真实支付、音频解码或视觉回归测试。
39. **可访问性**：以 WCAG 2.1 AA 为设计目标；由于无专业审计工具，按对比度与键盘路径自测，不宣称正式认证。
40. **图标与字体**：图标为手写 SVG；字体使用系统中文字体栈，不下载第三方字体，保证离线。
